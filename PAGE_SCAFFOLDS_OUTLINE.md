- `max-w-3xl mx-auto` content container

- Consistent header with navigation
- New footer component with links to all four legal pages + disclaimer line

### Routing
- Add routes to the React Router configuration in `App.jsx`
- Pages should be accessible without authentication (public routes)
- Add footer links to `Layout.jsx`

### SEO / Accessibility
- Semantic HTML headings (h1, h2, h3)
- Anchor-linked table of contents per page
- `<time>` elements for "last updated" dates
- Print-friendly styles (remove gradients, show full content)

- `[DANISH_BUSINESS_NAME]` — registered business name
- `[CVR_NUMBER]` — CVR registration number
- `[BUSINESS_ADDRESS]` — registered address

- `[HOSTING_PROVIDER]` — hosting service name
- `[EMAIL_PROVIDER]` — transactional email service
- `[ANALYTICS_PROVIDER]` — analytics service (if used)
- `[LOCATION]` — data processing location
- `{DATE}` — last updated date
