## Inclusion / exclusion rules

1. **Fox 1A remains the only Percy mascot**. None of these is a substitute fox. Full branded character scenes stay out until we have a real, usable vector master.
2. **Do not introduce fake graphics** or new mascot characters because a page looks empty.
3. Decorative stars are **not** the separately approved currency star. No decorative burst may change a point balance.
4. Acknowledgement moments can use animation only after approval, with reduced-motion fallback; a static source SVG must still look correct.
5. Don't overload dashboard lists: one spot art at a time, whitespace around instructions and accessible text labels.
6. **CC BY 4.0 attribution:** track each source path and author (Streamline), link to the licence, and disclose if colours are changed. The examples here retain original SVG files.
7. Premium Streamline illustrations/elements without accessible **licensed source files** are excluded from Stage 1 rather than substituted by generated artwork.

## Suggested display sizes to compare

| Location | Sizing range | Rule |
|---|---|---|
| Section accents / stickers | 28–48 px | Decorative, not controls |
| Empty-state spot art | 96–160 px | One large graphic |
| Redemption celebration | 120–200 px | Only after confirmed redemption |
| Parent onboarding | 120–180 px | Must clarify the instruction, not distract |
