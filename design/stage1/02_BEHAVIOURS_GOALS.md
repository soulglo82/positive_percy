The three examples are **placeholder text only**, not preconfigured tasks; there is no imposed goal list. The brief caps the compact dashboard presentation at **three items per selected child**. More goals can remain in the Manage Goals view if separately approved.

## Rules to preserve while selecting iconography

- The adult operates the checklist; no separate child login or approval queue.
- Each goal links to an existing behaviour category and its point value; don't render an editable points box on a goal.
- The parent can choose a child, set a short label, schedule goals and mark one complete. A repeat tap never awards twice.
- Undo follows the existing points ledger. Missing a goal never reduces points or breaks a streak.
- Render category symbols consistently in the Dashboard, Progress, Activity and Goals. Never change saved category IDs when changing an icon.
- Existing `src/lib/categoryIcons.js`, `server/iconKeys.js` and tests need coordinated key migration only **after selection**.
