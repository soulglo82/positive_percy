# Positive Percy — Stage 1 approved design-system handover

**Prepared:** 14 November 2026. **Status:** Design selections approved; Fox 1A logo exports delivered from the approved board; React QA and separate points-currency artwork still outstanding.

This archive is the specification pack for consistent styling in the Positive Percy **app, website, and documentation**. It contains implementation tokens, complete icon mapping manifests, selected reward-picker library, illustrations inventory, typography and logo export specs, and a styled PDF/HTML guide.

## Contents
- `01_Guide/Positive_Percy_Stage1_Style_Guide.pdf`: printable brand system
- `01_Guide/Positive_Percy_Stage1_Style_Guide.html`: offline visual style guide
- `02_Tokens/`: JSON/JS/CSS design tokens and category colours
- `03_Icons/`: all **38** exact icon mappings, **71** selected picker icons (across 84 category placements), three Goals SVG mappings, and 10 illustration contexts (CSV and JSON)
- `04_Illustrations/`: approved Freepik map source and nine Streamline placement references
- `05_Logos/`: **complete Fox 1A logo kit** with source-traced vector masters, PNGs, app icons, favicon, social graphics, printable PDFs and usage guide
- `06_Fonts/`: Nunito/Poppins licensing and implementation handover (no font binaries shared)
- `07_Engineering/`: integration and final QA gates

**Original SVG assets are already staged in the GitHub review branch**, linked from the manifests. The archive references rather than pretending to copy them. The exact selected `treasure-map_3570506.png` is included under `04_Illustrations/` as provided by the owner; asset-specific licence confirmation is still needed before public release.
